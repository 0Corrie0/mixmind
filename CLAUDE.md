# MIXMIND

A cocktail PWA. Vanilla JavaScript, no build step, no dependencies.

**Tagline:** Your second brain behind the bar.

---

## Files

| File | Purpose |
|---|---|
| `index.html` | The entire app — CSS and JS inline. Loads `data.js` |
| `data.js` | 90 drinks, shelf groups, ingredient aliasing. **The core IP** |
| `manifest.json` | PWA manifest |
| `sw.js` | Service worker, offline caching |
| `icon-192.png` / `icon-512.png` | App icons |
| `mixmind-standalone.html` | Generated single-file build for local preview. **Do not edit — regenerate it** |
| `docs/` | Deployment, Cloudflare, Midjourney, and commercial notes |

---

## Architecture

No framework. State lives in a single object `S`, and `render()` rebuilds the DOM from it. Views are functions returning a DOM node: `viewHome`, `viewResults`, `viewDrink`, `viewShelf`, `viewMakeable`, `viewAssay`, `viewHost`.

Navigate with `go("viewName", { patch })`. That merges the patch into `S`, scrolls to top, and re-renders.

Persistence is `localStorage` only. Keys are namespaced `mixmind.*`:
- `mixmind.shelf` — JSON array of owned ingredients
- `mixmind.endpoint` — override for the scan API endpoint
- `mixmind.hideInstall` — dismissed install prompt

## Data schema

```javascript
r("Drink Name", {
  base: ["gin"],           // gin whiskey rum tequila vodka brandy aperitivo sparkling zero
  family: "stirred",       // stirred shaken built long sparkling tropical swizzle
  era: "canon",            // canon | house | zero   (house = original IP)
  effort: 1,               // 1 two minutes | 2 some prep | 3 a project
  profile: ["bitter"],     // spirit-forward citrus bitter herbal sweet fruity smoky spiced creamy floral coffee
  theatre: "smoke",        // optional: smoke fire ice foam aroma
  glass: "Rocks",
  ice: "One large cube",
  garnish: "Orange twist",
  ingredients: [
    ["Gin", 30],                          // [name, millilitres]
    ["Angostura bitters", null, "3 dashes"] // [name, null, text] for non-metric
  ],
  method: ["Step one.", "Step two."],
  tip: "One line of hard-won advice.",
  note: "One line of character. Shown under the title."
});
```

`id` is auto-generated by slugifying the name.

**Adding a drink:** append an `r(...)` call in the relevant section of `data.js`. If it uses an ingredient not already in `SHELF_GROUPS`, add it there too, or shelf matching will silently treat the drink as unmakeable.

**Ingredient matching** runs through `shelfKey(name)`, which resolves `ALIASES` (e.g. "Bourbon or rye" → "Bourbon"). Things in `ASSUMED` (salt, mint, ice, espresso) are always treated as available.

## Regenerating the standalone build

After any change to `index.html` or `data.js`:

```bash
python3 - << 'PY'
data = open('data.js').read()
data = "\n".join(l for l in data.split("\n") if "module.exports" not in l and "typeof module" not in l)
html = open('index.html').read()
html = html.replace('<script src="data.js"></script>', '<script>\n' + data + '\n</script>')
html = html.replace('if ("serviceWorker" in navigator) {',
                    'if ("serviceWorker" in navigator && location.protocol.startsWith("http")) {')
open('mixmind-standalone.html','w').write(html)
PY
```

## Testing

`data.js` is valid Node, so it can be required directly:

```bash
node -e "const d=require('./data.js'); console.log(d.DRINKS.length)"
```

Full check — every drink renders, no console errors:

```bash
python3 -c "
from playwright.sync_api import sync_playwright
with sync_playwright() as p:
    b=p.chromium.launch(); pg=b.new_page(viewport={'width':430,'height':932})
    errs=[]; pg.on('pageerror', lambda e: errs.append(str(e)))
    pg.goto('file://\$(pwd)/mixmind-standalone.html'); pg.wait_for_timeout(700)
    n=pg.evaluate('DRINKS.length')
    for i in range(n): pg.evaluate(f'go(\"drink\",{{drink:DRINKS[{i}].id}})')
    print('drinks:',n,'errors:',errs or 'none'); b.close()
"
```

Also verify no recipe references an ingredient missing from the shelf list:

```bash
node -e "
const d=require('./data.js');
const shelf=new Set(d.SHELF_GROUPS.flatMap(g=>g.items));
const bad=new Set();
d.DRINKS.forEach(x=>x.ingredients.forEach(i=>{
  const k=d.shelfKey(i[0]);
  if(!shelf.has(k)&&!d.ASSUMED.has(k)) bad.add(i[0]);
}));
console.log(bad.size ? [...bad] : 'all resolve');
"
```

## Design system — do not drift from this

| Token | Value | Use |
|---|---|---|
| `--ink` | `#12100F` | Page background. Warm bitumen, not neutral black |
| `--glass` | `#17201C` | Raised surfaces |
| `--copper` | `#B87333` | Primary accent, numbers, actions |
| `--verdigris` | `#3E7A6B` | Secondary accent, metadata |
| `--mercury` | `#CFC9BC` | Secondary text |
| `--vellum` | `#EDE4D0` | Primary text |

**Type:** Bodoni Moda (display), Spectral (body), Space Grotesk (uppercase utility labels, wide letter-spacing).

Signature elements: the segmented brass dial on the home screen, and the corner-bracketed specimen label on recipe cards. Keep both.

## Known state / what's outstanding

1. **The scan feature needs a proxy.** `S.endpoint` is empty by default; the Scan screen asks for the Worker URL and stores it in `mixmind.endpoint`. Photos are downscaled to 1600px JPEG before upload. `docs/SCAN-SETUP-CLOUDFLARE.md` has the Worker code. **Never put an API key in client-side files.**
2. **No recipe images.** `docs/MIDJOURNEY-PACK.md` has the prompts and the wiring code. The `img.onerror` pattern means images can be added incrementally without breaking the layout.
3. **Name not trademark-cleared.** MIXMIND has no cocktail-app collision in app store or web search, but USPTO TESS and the UAE registry have not been checked.
4. `sw.js` is network-first (cache is offline fallback only). Still bump `CACHE` and the `data.js?v=` query when changing assets.

## House style for recipe copy

The `note` and `tip` fields carry the brand voice. Declarative, specific, faintly opinionated. No hedging, no exclamation marks, no "simply" or "just".

Good: *"The twist is not decoration. The orange oil is half the drink."*

Bad: *"Don't forget to add a lovely orange twist for extra flavour!"*

`note` is one line of character or history. `tip` is the thing that actually stops the drink being bad.
