# MixMind

Your second brain behind the bar. 90 cocktails, shelf matching, party batching.

## Look at it right now
Open `mixmind-standalone.html` in any browser. No setup.

## Put it online (10 min, gets you the install button)
Upload `index.html`, `data.js`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`
to a GitHub repo → Settings → Pages → deploy from main.

Full walkthrough: `docs/PUT-IT-ONLINE.md`
